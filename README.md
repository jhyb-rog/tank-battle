# 坦克大战 (Battle City)

一个用纯 HTML + Canvas + JavaScript 编写的经典坦克大战小游戏，单文件即可运行，无需任何依赖。

## 玩法

- **方向键 / WASD**：移动
- **空格 / J**：射击
- **P**：暂停
- **Enter**：开始 / 重新开始

## 特性

- 4 个关卡，逐步增加难度
- 地形：砖墙（可摧毁）、钢墙、水面、树林（坦克可从下穿过）
- 4 种敌人：普通、快速、火力、装甲（需 4 次命中）
- 道具：火力提升 ⭐、手雷 💣、护盾 🛡、加命 ❤
- 保护基地（★），消灭所有敌人即可过关
- Web Audio 音效，无需外部资源

## 在线试玩

- 直接双击 `index.html` 在浏览器中打开
- 或在 GitHub 仓库 `Settings → Pages` 中开启 GitHub Pages，选择分支后即可在线游玩
